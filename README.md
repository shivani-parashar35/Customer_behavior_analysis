Customer Shopping Behavior Analysis

📌 Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data loading and exploration to data cleaning, SQL analysis, interactive dashboard creation, and business reporting.

The objective is to transform raw data into meaningful insights and actionable business recommendations using Python, SQL, Power BI, and presentation tools.

📂 Dataset

The project uses a structured dataset containing relevant business/customer transaction data.

The dataset was:

• Loaded and explored using Python 
• Checked for missing values and duplicates
• Cleaned and prepared for analysis
• Loaded into a relational database for SQL analysis
• Connected to Power BI for visualization

🛠️ Tools & Technologies

• Python (Pandas, NumPy, Matplotlib, Seaborn) - Data loading, cleaning & EDA    
• SQL (MySQL / PostgreSQL / SQL Server) - Query and insights generation          
• Power BI - Interactive dashboard, dashboard building and data visualization            
• Gamma - Business report and presentation / PPT  creation
• GitHub - Version control and project sharing 

🔄 Project Workflow

1️. Data Loading

• Imported the raw dataset into Python.
• Used Pandas to inspect the structure and contents of the data.
• Checked columns, data types, number of records, and basic statistics.

2️. Exploratory Data Analysis (EDA) 

• Data distribution
• Key numerical and categorical variables
• Trends and patterns
• Missing values, Duplicate records
• Outliers
• Relationships between variables

3️. Data Cleaning 

• Handling missing values
• Removing duplicate records
• Correcting data types
• Standardizing categorical values
• Handling inconsistent data
• Identifying and treating outliers where required

4️. SQL Analysis 

• Created and connected databases in MySQL, SQL Server
• Ran queries for insights (joins, aggregates, filtering)
• Validated analysis against Python results

5️. Power BI Dashboard 

• Designed an interactive dashboard with KPIs, charts and filters
• Explored the data and identified important business trends.
• Highlighted actionable insights

6️. Business Report and Presentation 

• A detailed report was prepared to summarize business problem, data preparation process, key findings, important KPIs, business insights, recommendations
• A concise presentation was created using Gamma to communicate the project to stakeholders.

📊 Dashboard

💡 Key Results & Insights

The analysis helped identify:

Important trends and patterns in the dataset
• High-performing and underperforming categories

• Key factors influencing business performance

The insights were converted into data-driven recommendations that can support better business decision-making.
